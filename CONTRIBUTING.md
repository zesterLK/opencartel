# Contributions and issues

OpenCartel is a collection maintained by one author. External pull requests are not currently accepted. Issues can be used for bugs, broken examples, or questions about a published implementation; suggestions do not imply a commitment to build or support them.

For a bug report, include:

- The project directory and commit or release you used.
- Browser, operating system, and relevant runtime versions.
- Minimal steps to reproduce, expected behavior, and actual behavior.
- Relevant logs or a screenshot with credentials and private information removed.

Never include secrets, customer data, or private project material in an issue. Avoid posting exploit details publicly before a fix is available.

Forking and adapting the projects is encouraged within the applicable licenses. Preserve required notices and check the individual project's asset credits.
