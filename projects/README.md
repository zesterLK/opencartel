# Projects

## Available locally

- [Words Have Weight](words-have-weight/) — An interactive typography playground with six physical word behaviours. Source, standalone setup, tests, and asset credits are included. Ready for local use; [public demo](https://opencartel.tech/words-have-weight/).
- [Paper Shredder](paper-shredder/) — An interactive paper shredder in an illustrated office after hours. Ready for local use, with local-file previews, office interactions, queue and speed controls. No public demo has been published.

Run the collection using the [repository setup](../README.md#run-the-collection), or follow a project's README to run it independently. Add verified public demo links only after publication.

See the [project standard](../docs/project-standard.md) before adding an implementation.
